# Karthick A — Portfolio

Modern, high-performance developer portfolio built for Karthick A, Full Stack Developer specializing in DevOps, Generative AI, LLMs, and RAG architectures.

## Features
- **Modern Tech Stack**: Built with TanStack Start, React 19, TypeScript, Tailwind CSS, shadcn/ui, and Framer Motion.
- **Dynamic Themes**: Full light & dark mode support with synchronized color tokens and interactive theme toggle.
- **Interactive UI**: Animated skill bars, count-up statistics, tabbed case study filters, architecture modal flows, and responsive mobile navigation.
- **Production Ready**: Optimized performance, responsive layout, type-safe routes, and comprehensive SEO meta tags.

## Quick Start
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
